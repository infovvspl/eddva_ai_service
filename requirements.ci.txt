# Minimal dependency set for running the test suite in CI.
#
# The tests exercise settings, middleware, the prompt/vertical registries, the
# concurrency gate and the bridge views. None of that needs the heavy runtime
# extras (torch, rdkit, easyocr, faster-whisper, sentence-transformers) — those
# are imported lazily inside the functions that use them, so CI stays fast
# (~30s instead of pulling several GB of wheels).
#
# If a test ever fails in CI with ModuleNotFoundError, add the module here
# rather than switching CI to the full requirements.txt.
